# Trade Hub — Wholesale Website

Trade Hub is a Dubai & Sharjah based wholesale trading company with 10+ years of experience. The website is a premium catalogue-first B2B website.

## Pages
- Home
- Wholesale Catalogue
- Product Detail
- About Trade Hub
- Wholesale & Shipping
- Contact
- Private Owner Admin

## Categories
Perfumes, junior/adult trousers, ladies premium bags, formal shoes, sneakers, skincare and makeup.

## Important
- Public product prices are intentionally hidden.
- Product detail pages show MOQ.
- Favicon is branded **TH** for Trade Hub.
- Contact page currently contains placeholders for phone, WhatsApp and email.
- Admin page is a front-end layout only. For real owner-only publishing, connect Supabase Auth + Database + Row Level Security.
